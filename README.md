# Aqua5230 Leakbolt

## How do I install these formulae?

`brew install aqua5230/leakbolt/<formula>`

Or `brew tap aqua5230/leakbolt` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "aqua5230/leakbolt"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
